Help Center

Jawaban cepat dan kontak support OLPI STORE.

API Key saya hilang, bisa ditampilkan lagi?

Tidak. AYAKA hanya menyimpan hash key. Gunakan Regenerate di API Key Manager — key lama langsung tidak berlaku.

Kenapa request saya mendapat 401 INVALID_API_KEY?

Pastikan header bernama X-API-Key, key lengkap diawali ayaka_live_, belum di-revoke, dan belum kedaluwarsa.

Kenapa mendapat 403 INSUFFICIENT_PERMISSION?

Key tidak memiliki permission yang dibutuhkan endpoint. Edit permission key di API Key Manager.

Magic Link tidak sampai ke email.

Periksa folder spam, pastikan alamat benar, dan cek status pengiriman di Riwayat Magic Link. Pengiriman dibatasi 5 kali per 15 menit per email.

Apa arti 429 RATE_LIMITED?

Batas request per menit key terlampaui. Tunggu sesuai header Retry-After atau naikkan limit key.
