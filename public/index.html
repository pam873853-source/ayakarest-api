02 — Fitur

Dibangun untuk produksi, bukan untuk demo.

Setiap tombol terhubung ke backend FastAPI dan database Neon PostgreSQL sungguhan.

API Key Management

Generate key berformat ayaka_live_… dengan CSPRNG. Secret hanya tampil sekali, database hanya menyimpan HMAC-SHA256 berpepper.

  • Nama, deskripsi, permission granular & expiration date
  • Revoke instan, regenerate (rotasi), last used & riwayat
  • Rate limit per key & kuota bulanan per akun

Magic Link Premium

Kirim tautan verifikasi lewat Resend. Token sekali pakai, di-hash, kedaluwarsa 15 menit. Aktivasi, perpanjangan, dan pencabutan Premium tercatat lengkap.

Security

Argon2id, cookie HttpOnly + Secure + SameSite, CSRF token, rate limiting, proteksi brute force, security headers, audit log, dan isolasi data antar pengguna.

Real-Time Analytics

Grafik request per menit/jam/hari, success vs failed, API Key dibuat, pengunjung, aktivasi Premium — diperbarui otomatis tiap 4 detik.

API Playground

Coba endpoint langsung dari browser: pilih method, isi header X-API-Key & JSON body, lihat status, waktu respons, dan respons lengkap.

Webhooks, Logs & Admin AYAKA Sync

Webhook bertanda tangan HMAC untuk event key & premium. Request log dengan filter, pencarian, pagination, dan export CSV. Admin dashboard dengan monitoring server, database, Resend, serta Maintenance Mode.

03 — Contoh Penggunaan

Kirim Magic Link dalam 10 baris.

Ganti Base URL dan API Key Anda, lalu jalankan. Contoh tersedia untuk JavaScript Fetch, PHP cURL, Python Requests, dan cURL.

Penting: API Key adalah secret. Jangan taruh di kode frontend publik — panggil AYAKA API dari server Anda dan simpan key di environment variable.
  1. Register & login ke dashboard.
  2. Buka API Key Manager → Generate dengan permission premium:send.
  3. Salin key (hanya tampil sekali) ke server Anda.
  4. Panggil POST /api/am/send.
const BASE_URL = "https://YOUR-AYAKA-DOMAIN.vercel.app";
const API_KEY = process.env.AYAKA_API_KEY; // ayaka_live_...

const res = await fetch(`${BASE_URL}/api/am/send`, {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-API-Key": API_KEY },
  body: JSON.stringify({ email: "user@example.com", plan: "premium" })
});
const result = await res.json();
if (!res.ok) throw new Error(result.message);
console.log(result.data); // { email, plan, expires_in: 900 }
<?php
$baseUrl = "https://YOUR-AYAKA-DOMAIN.vercel.app";
$apiKey  = getenv("AYAKA_API_KEY");

$ch = curl_init($baseUrl . "/api/am/send");

05 — FAQ

Pertanyaan yang sering diajukan

Apakah AYAKA API gratis digunakan?
Ya. Setiap akun mendapat kuota bulanan (default 10.000 request) dan rate limit per API Key. Administrator AYAKA Sync dapat menyesuaikan kuota.
Bagaimana jika saya kehilangan API Key?
Secret hanya ditampilkan sekali dan tidak disimpan dalam bentuk mentah. Gunakan tombol Regenerate untuk membuat key baru — key lama langsung nonaktif.
Apakah API Key boleh dipakai di JavaScript browser?
Tidak disarankan. Kode browser bisa dibaca siapa saja. Panggil AYAKA API dari backend Anda (Node, PHP, Python) dan simpan key di environment variable server.
Bagaimana Magic Link Premium bekerja?
Aplikasi Anda memanggil /api/am/send. AYAKA API membuat token acak, menyimpan hash-nya, dan mengirim email via Resend. Saat pengguna mengklik Verify Account, Premium aktif. Token hanya bisa dipakai sekali dan kedaluwarsa 15 menit.
Apakah data Premium antar developer bisa saling terlihat?
Tidak. Setiap langganan Premium terikat pada pemilik API Key (owner_id). Developer lain tidak dapat membaca, memperpanjang, atau mencabut pelanggan Anda.
Bagaimana pengunjung dihitung?
Tanpa cookie pelacak. Kami memakai hash anonim harian (HMAC dari tanggal, IP, dan user-agent) sehingga refresh tidak dihitung sebagai pengunjung baru. Data disimpan maksimal 90 hari dan Do-Not-Track dihormati.
