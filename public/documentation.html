AYAKA API · v1

Dokumentasi AYAKA API

REST API berbasis JSON untuk mengelola API Key, mengirim Magic Link Premium lewat email, dan membaca analytics/logs akun Anda. Base URL:

Base URL
https://YOUR-AYAKA-DOMAIN.vercel.app

Spesifikasi OpenAPI interaktif tersedia di /api/swagger · JSON ringkas di /api/docs · Powered by AYAKA Sync.

Quickstart

  1. Register akun lalu login ke dashboard.
  2. Buka API Key Manager → Generate API Key, pilih permission yang dibutuhkan.
  3. Salin API Key (ayaka_live_…). Key hanya ditampilkan satu kali; simpan di environment variable server Anda.
  4. Kirim request dengan header X-API-Key. Coba langsung di API Playground.

Autentikasi

Semua endpoint yang dilindungi menerima API Key hanya melalui header HTTP:

X-API-Key: ayaka_live_YOUR_SECRET_KEY
Jangan kirim API Key lewat URL. Request seperti ?api_key=… ditolak dengan 400 API_KEY_IN_URL karena URL tercatat di log server, history browser, dan referrer.

API Key disimpan di database sebagai hash HMAC-SHA256 (dengan pepper server). AYAKA tidak bisa menampilkan ulang key Anda — jika hilang, regenerate dari dashboard.

Endpoint manajemen sensitif seperti POST /api/keys/generate hanya dapat dipanggil dari dashboard yang sudah login (cookie sesi HttpOnly + token CSRF), bukan dengan API Key.

Permissions

Setiap API Key memiliki daftar permission. Request ke endpoint tanpa permission yang sesuai mendapat 403 INSUFFICIENT_PERMISSION.

Format Respons

Semua respons JSON memakai format yang konsisten.

Berhasil
{
  "success": true,
  "message": "Request successful",
  "data": {},
  "timestamp": "2026-01-01T00:00:00Z"
}
Gagal
{
  "success": false,
  "message": "Invalid API Key",
  "error": { "code": "INVALID_API_KEY" },
  "timestamp": "2026-01-01T00:00:00Z"
}

Setiap respons juga menyertakan header X-Request-ID — sebutkan ID ini saat menghubungi support.

Rate Limit & Kuota

Setiap API Key memiliki batas request per menit (default diatur admin, dapat disesuaikan per key) dan akun memiliki kuota bulanan. Header respons:

  • X-RateLimit-Limit — batas per menit
  • X-RateLimit-Remaining — sisa request di jendela saat ini
  • Retry-After — detik menunggu saat menerima 429

Pengiriman Magic Link dibatasi 5 kali per 15 menit untuk email yang sama.

GET — Profil

Membaca profil pemilik API Key. Permission: profile:read.

GET — Daftar API Key

Metadata seluruh key milik akun (tanpa secret). Permission: keys:read.

POST — Kirim Magic Link Premium

Mengirim email berisi tombol Verify Account ke pengguna. Token berlaku 15 menit dan hanya bisa dipakai satu kali. Permission: premium:send.

Body: email (wajib), plan (premium=30 hari, premium_quarterly=90, premium_yearly=365), duration_days (opsional 1–365), name (opsional).

DELETE — Revoke API Key

Mencabut key milik akun Anda secara permanen; berlaku seketika. Permission: keys:revoke.

Alur Magic Link Premium

  1. Server Anda memanggil POST /api/am/send dengan email pengguna.
  2. AYAKA Sync membuat token acak (disimpan sebagai hash SHA-256) dan mengirim email via Resend.
  3. Pengguna menekan Verify Account → halaman konfirmasi /api/am/verif?token=… → tombol konfirmasi mengirim POST (mencegah pemindai link email mengonsumsi token).
  4. Premium aktif; email konfirmasi aktivasi dikirim, dan webhook premium.activated dipicu.
  5. Server Anda mengecek GET /api/am/status, memperpanjang dengan /renew, atau mencabut dengan /revoke.

Verify Token

Biasanya dilakukan otomatis lewat tombol di email. Jika Anda membangun halaman verifikasi sendiri, kirim token ke endpoint ini (tidak butuh API Key).

Cek Status Premium

Permission: premium:status. Nilai status: active, expired, revoked, atau none.

Renew Premium

Menambah durasi (hari) dari tanggal kedaluwarsa saat ini atau dari sekarang jika sudah lewat. Permission: premium:renew.

Revoke Premium

Mencabut Premium seketika dan mengirim email pemberitahuan. Permission: premium:revoke.

Webhooks

Atur URL HTTPS di Webhook Settings. AYAKA mengirim POST JSON untuk event: key.created, key.revoked, key.regenerated, premium.link_sent, premium.activated, premium.renewed, premium.revoked.

Header: X-Ayaka-Event, X-Ayaka-Timestamp, X-Ayaka-Signature: sha256=HMAC_SHA256(secret, timestamp + "." + rawBody). Tolak request dengan timestamp lebih dari 5 menit.

Keamanan

  • Panggil AYAKA API dari backend Anda. API Key di JavaScript browser dapat dibaca siapa pun.
  • Berikan permission seminimal mungkin dan gunakan tanggal kedaluwarsa.
  • Rotasi key secara berkala (Regenerate) dan revoke key yang bocor seketika.
  • Verifikasi signature setiap webhook sebelum memprosesnya.
  • AYAKA tidak pernah mencatat API Key, token, atau password di request logs.
